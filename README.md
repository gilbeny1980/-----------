# מערכת מחלקת חשמל, גלעם

מערכת web פנימית למחלקת החשמל: מעקב פרויקטים, ניהול חשמלאים והודעות למחלקה, עם מסך תצוגה שאפשר להציג במחלקה.

## יכולות נוכחיות

- **מסך תצוגה (`/`)** – מסך בקרה מלא (כהה, פונטים גדולים) המיועד להצגה על מסך/טלוויזיה: סטטוס פרויקטים פעילים, ופיד עדכונים חי (ימי הולדת + הודעות למחלקה). מתרענן אוטומטית כל דקה.
- **פרויקטים (`/projects`)** – ניהול רשימת פרויקטים: שם, תיאור, סטטוס (לביצוע/בטיפול/בוצע), הפעלה/השבתה, מחיקה, והערות חופשיות על כל פרויקט.
- **חשמלאים (`/electricians`)** – הוספה, עריכה (כולל תאריך לידה), השבתה/הפעלה ומחיקה.
- **הודעות (`/announcements`)** – הודעות טקסט חופשיות למחלקה, מוצגות במסך התצוגה יחד עם ימי הולדת.
- **קישור צפייה בלבד** – הוספת `?view=1` לכתובת האתר (למשל `https://.../?view=1`) נותנת לצופה גישה לקריאה בלבד לצמיתות: כל כפתורי ההוספה/עריכה/מחיקה מוסתרים, וגם ניסיון ישיר לשמור נחסם בשרת.

## הרצה מקומית

```bash
npm install
npx prisma migrate dev   # יצירת מסד הנתונים המקומי (SQLite)
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

## טכנולוגיות

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma ORM + SQLite מקומי לפיתוח, Turso (libSQL) בפרודקשן
- Server Actions לכל פעולות היצירה/עדכון/מחיקה
- `src/proxy.ts` מטפל בקישור הצפייה-בלבד (מגדיר cookie); `src/lib/role.ts` בודק אותו בכל דף ובכל פעולה

## הרחבות עתידיות אפשריות

- התחברות משתמשים / הרשאות מלאות
- אינטגרציה עם מערכת אחזקה חיצונית (אם תהיה גישה ציבורית/API)
- צירוף תמונות להודעות/פרויקטים
