# מערכת ניהול משימות - מחלקת חשמל, גלעם

מערכת web פנימית לניהול קריאות ותקלות ומשימות עבור מחלקת החשמל.

## יכולות נוכחיות

- **מסך תצוגה (`/`)** – מסך בקרה מלא (כהה, פונטים גדולים) המיועד להצגה על מסך/טלוויזיה בחדר הבקרה: תקלות דחופות לטיפול, סטטוס פרויקטים פתוחים, ופיד עדכונים חי. מתרענן אוטומטית כל דקה.
- **כל המשימות (`/tasks`)** – רשימת כל המשימות עם סינון לפי סטטוס, עדיפות, פרויקט וחשמלאי, וסיכום מספרי.
- **פתיחת משימה חדשה** – כותרת, תיאור, מיקום, עדיפות, פרויקט, פרטי פונה, תאריך יעד ושיוך לחשמלאי.
- **עריכת משימה** – עדכון סטטוס, עדיפות, שיוך לפרויקט/חשמלאי, ומחיקה.
- **פרויקטים (`/projects`)** – ניהול רשימת פרויקטים חופשית שאליהם ניתן לשייך משימות.
- **ניהול חשמלאים** – הוספה, השבתה/הפעלה ומחיקה.
- **יומן עדכונים אוטומטי** – כל פתיחת/עדכון/מחיקת משימה או פרויקט נרשמת אוטומטית ומוצגת במסך התצוגה.

## הרצה מקומית

```bash
npm install
npx prisma migrate dev   # יצירת מסד הנתונים המקומי (SQLite)
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

## טכנולוגיות

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma ORM + SQLite (קובץ מקומי `prisma/dev.db`)
- Server Actions לכל פעולות היצירה/עדכון/מחיקה

## הרחבות עתידיות אפשריות

- התחברות משתמשים / הרשאות
- התראות (SMS/וואטסאפ) לחשמלאי כשמשויכת אליו משימה
- צירוף תמונות לתקלה
- הערות חופשיות על משימה (בנוסף ליומן העדכונים האוטומטי)
