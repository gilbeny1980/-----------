# מערכת ניהול משימות - מחלקת חשמל, גלעם

מערכת web פנימית לניהול קריאות ותקלות ומשימות עבור מחלקת החשמל.

## יכולות נוכחיות

- **לוח משימות** – רשימת כל המשימות עם סינון לפי סטטוס, עדיפות וחשמלאי, וסיכום מספרי (חדשות / בטיפול / הושלמו / דחוף ופתוח).
- **פתיחת משימה חדשה** – כותרת, תיאור, מיקום, עדיפות, פרטי פונה, תאריך יעד ושיוך לחשמלאי.
- **עריכת משימה** – עדכון סטטוס, עדיפות, שיוך לחשמלאי, ומחיקה.
- **ניהול חשמלאים** – הוספה, השבתה/הפעלה ומחיקה.

## הרצה מקומית

```bash
npm install
npx prisma migrate dev   # יצירת מסד הנתונים המקומי (SQLite)
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

## טכנולוגיות

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma ORM + SQLite (קובץ מקומי `prisma/dev.db`)
- Server Actions לכל פעולות היצירה/עדכון/מחיקה

## הרחבות עתידיות אפשריות

- התחברות משתמשים / הרשאות
- התראות (SMS/וואטסאפ) לחשמלאי כשמשויכת אליו משימה
- צירוף תמונות לתקלה
- היסטוריית פעולות/הערות על משימה
